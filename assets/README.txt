PROFILE PHOTO
=============

Place your professional profile photo in this folder as:

    rahman.jpeg   (also mirrored at react-app/public/assets/rahman.jpeg)

The hero section loads it automatically:
  - Static version: html/index.html (src="../assets/rahman.jpeg")
  - React version: react-app/src/components/Hero.jsx (src="/assets/rahman.jpeg")

If the photo is missing, the site falls back to showing your
initials "AR" with a "Photo coming soon" label — so the site
looks complete even before you add the image.

Recommended: a 4:5 portrait crop, at least 800x1000px, well lit,
saved as a real JPEG (not a PNG renamed to .jpeg).
